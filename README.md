# NYC Parking Finder

Find parking in New York City — both **on-street metered spots** (free or
metered right now, based on posted meter hours) and **off-street
garages/lots** (location + total capacity). Filter to either type or see
both together.

## What this is (and isn't)

NYC does not publish a free, public feed of real-time parking occupancy —
the city's old sensor-based systems (and SFpark-style approaches elsewhere)
were discontinued years ago, and true live occupancy today is only available
through paid private providers (e.g. Parknav, SpotHero).

Instead, this app uses [NYC Open Data's Parking Meters Locations and
Status](https://data.cityofnewyork.us/Transportation/Parking-Meters-Locations-and-Status/693u-uax6)
dataset, which gives the real location of every active parking meter plus its
posted regulation text (e.g. `"2HR Pas Mon-Sat 0900-1900"`). The app parses
that text and computes, for the current moment in New York time, whether the
meter is:

- 🟢 **Free** — no metered restriction in effect right now
- 🔴 **Metered** — paid, time-limited parking in effect right now
- ⚪ **Unknown** — the posted text didn't match a known pattern (shown as
  gray in the popup detail; check the physical sign)

This tells you **where parking is legal and what it costs**, not whether a
specific space is currently occupied by a car. It also does not account for
alternate-side parking, no-standing zones, construction closures, or other
DOT regulations beyond meter hours — those live in a much larger, harder to
parse dataset and are a natural next step.

### Off-street garages/lots

Alongside meters, the app shows licensed garages/lots from NYC's DCA
registry — 🟦 square markers, distinct from street parking's round ones.
Each shows a name, address, and **total vehicle capacity** (a static
license figure, not a live count). There's no rate/price data for garages
in NYC's free open data (see
[GARAGE_DATA_RESEARCH.md](GARAGE_DATA_RESEARCH.md) for what was checked and
ruled out). Toggle the **Street** / **Garages** buttons in the toolbar to
show or hide each type independently — both are on by default. The AI
assistant's default search follows the same toggles.

### Cost — street rates and sorting

Street spots often show a posted hourly rate (e.g. "$5.50/hr, Midtown
zone") from NYC DOT's meter rate-zone data — shown in the map popup, the
new **list panel**, and the AI assistant's results. There's a **List**
button (bottom-left) that opens a panel of every spot currently loaded,
sortable by Distance or Cost; ask the AI assistant for "the cheapest spot
near X" and it sorts the same way. Garages have no rate data anywhere in
NYC's free sources (see GARAGE_DATA_RESEARCH.md) — they, and any street
spot outside a known rate zone, sort to the *end* under cost sorting
rather than being treated as free.

### Crowdsourced occupancy (optional, street parking only)

Since there's no free live-occupancy feed for on-street parking, metered
spots also support **crowdsourced reports**: anyone can tap "I saw an
opening here" from a spot's popup. Multiple reports within a 30-minute
window corroborate each other into a confidence level (low/medium/high)
rather than one person's single, overwritable tap — shown as a blue ring
around the marker plus the report count and confidence in the popup. This
is opt-in infrastructure: it only activates when
`UPSTASH_REDIS_REST_URL`/`UPSTASH_REDIS_REST_TOKEN` are configured (see
below); without them, `/api/report` returns 503 and spots just show meter
status as usual. (There's no equivalent for garages — see
`GARAGE_DATA_RESEARCH.md`.)

## Stack

- **Next.js 16** (App Router, TypeScript, Turbopack)
- **Tailwind CSS 4**
- **Leaflet / react-leaflet** with OpenStreetMap tiles (no API key required)
- **NYC Open Data** (Socrata) for parking meter locations + regulation text,
  the DCA licensed-garage registry, and meter rate-zone polygons (street
  hourly rates)
- **Nominatim (OpenStreetMap)** for address geocoding, proxied through a
  server route
- **Upstash Redis** (optional) for crowdsourced occupancy reports, TTL'd
  key-value only — no relational data, so no ORM/schema needed
- **AI SDK v6** (`ToolLoopAgent`) with **OpenAI** (`gpt-5.4-mini`) for an
  optional grounded chat assistant
- Deploys to **Vercel**

The meter and geocoding data are queried live through Next.js API routes
(`/api/parking`, `/api/geocode`) that act as thin, cached proxies. Occupancy
reports go through `/api/report`, which writes to Redis with a 30-minute
expiry. The AI assistant streams through `/api/chat`, backed by a single
tool (`findParking`) that reuses the same server-side spot-fetching logic —
nothing about a parking spot is ever generated by the model itself.

## Running locally

```bash
npm install
npm run dev
```

Open http://localhost:3000. The map loads centered on Union Square and
fetches meters in the visible viewport; pan/zoom or search an address to
load a different area (auto-refreshes ~500ms after you stop moving the map).

### Optional: NYC Open Data app token

The Socrata API works unauthenticated but is rate-limited. For heavier use,
get a free app token at https://data.cityofnewyork.us/profile/app_tokens and
set it as an env var:

```bash
# .env.local
NYC_OPEN_DATA_APP_TOKEN=your_token_here
```

### Optional: crowdsourced occupancy reports (Upstash Redis)

To enable the "It's open" / "It's taken" reporting feature:

1. Sign up at https://console.upstash.com (free tier, no card required) and
   create a Redis database.
2. On the database's page, copy the REST API **URL** and **token**.
3. Add them to `.env.local`:

```bash
# .env.local
UPSTASH_REDIS_REST_URL=your_url_here
UPSTASH_REDIS_REST_TOKEN=your_token_here
```

Without these, the app still works — metered/free status just won't have a
crowdsourced availability layer on top.

### Optional: AI parking assistant

A chat panel ("Ask AI") lets you ask things like *"free parking near Union
Square"* or *"a 2-hour spot near Times Square"*. It's grounded: the
assistant can only answer using a tool that calls the exact same
spot-fetching and status logic the map uses — it cannot invent a street,
status, or distance.

1. Get an API key at https://platform.openai.com/api-keys.
2. Add it to `.env.local`:

```bash
# .env.local
OPENAI_API_KEY=your_key_here
```

Without this, the map and reporting still work — the "Ask AI" button just
won't have a model to talk to (`/api/chat` will error).

## Deploying to Vercel

```bash
vercel
```

No environment variables are required for a basic deploy; add
`NYC_OPEN_DATA_APP_TOKEN`, the two `UPSTASH_REDIS_REST_*` vars, and/or
`OPENAI_API_KEY` in the Vercel project settings (or `vercel env add`) if
you're using them.

## Known limitations / next steps

- Meter-hours text parsing covers the common patterns (`"NHR Class Day-Day
  HHMM-HHMM"`, optionally chained with `/` and `,`) but not every historical
  format in the dataset — unparseable entries are labeled "Unknown" rather
  than guessed.
- Broader DOT regulation signs (no-standing, alternate-side, loading zones)
  aren't included yet — only meters and licensed garages.
- Street rates come from large neighborhood/borough-sized zone polygons — a
  viewport that straddles two rate zones will show one zone's rate for the
  whole visible area (the app queries the zone at the viewport's center,
  not per spot).
- No rate/price data exists for garages in any free NYC data source (also
  checked and ruled out: `dotprs.nyc`, DOT's own municipal-garage
  reservation site) — see SUGGESTIONS.md.
- Garage listings come from a DCA business-license registry, filtered to
  non-expired licenses — licensing can lag real-world status (a garage
  could have closed without the license record reflecting it yet).
- Results are capped at 400 street spots / 200 garages per viewport to keep
  the map responsive — zoom in on dense areas (Midtown, Downtown) to see
  everything.
- Crowdsourced reports (street only) are anonymous and unmoderated — nothing
  currently limits repeat/spam reports beyond the 30-minute rolling window.
  Fine for a demo; would need rate-limiting and/or a trust signal before
  relying on it for real decisions.
